## 数学与性能对比

用优化前的距离差分代码作为基线，与本包的解析法线加极窄接缝差分进行位移贴图比较。

四组测试：360×240/r28、900×70/r28、600×600/r28、120×120/r60。中心通道保持 128，Alpha 均为 255。

- 平均 RG 通道绝对差：0.00032073/255。
- 最大通道差：1/255。
- 600×600，预热 3 次，采样 9 次的中位数：基线 7.60ms，本包 4.59ms。
- 本次样本约减少 40% CPU 计算时间。

复现命令：

```sh
node demo/benchmark.mjs
```

这只测 Node.js 内的像素数学及数组写入，不包含 PNG 编码、DOM 合成或 GPU 采样。耗时会随机器和负载变化，不能据此推导帧率。解析法线在极窄分段接缝上保留差分，避免相较原版出现方向跳变。
