日期：2026-10-18。环境：Windows / Node.js v26.10.0 / Codex 内置桌面 Chromium。

## 当前正式效果

用户选定 B 的圆形 Lens 曲线与受控色散，旧宽弧面和直接 RGB 分离实现已移除。Full 和 Light 均使用 Lens 贴图，原有双文件接入、参数范围、质量档位和兼容性回退保留。

默认 refraction=110、dispersion=14、edgeWidth=44。三个通道位移约为 109.8152/110/110.1848，RGB 结果按 5.6% 与绿色基准采样混合；默认仍在折射后使用 3px 浏览器高斯模糊。没有移植 native 的有限 25 点采样核、投影或 depth 效果，不能当作 native 逐像素一致的复现。

## 原始 B 迁移时的一致性记录

在修改默认值之前，使用模拟 Canvas 对正式实现与 B 实验做逐字节比较，以下显式几何参数的 6/6 组 RGBA 完全相同。此处保留迁移记录；当前默认边缘带宽已改为 44px：

| 贴图尺寸 | 圆角 | edgeWidth | CSS 缩放比例 |
| --- | ---: | ---: | ---: |
| 360×240 | 28 | 58 | 1 |
| 900×70 | 28 | 58 | 1 |
| 600×600 | 21 | 58 | 0.75 |
| 120×120 | 60 | 30 | 1 |
| 301×201 | 0 | 58 | 1 |

这项比较证明移除 A 分支和冗余法线计算没有改变 B 的这些贴图样本，不代表完整浏览器渲染与 native 一致。

## 数学与 CPU 计时

```sh
node demo/benchmark.mjs
```

脚本直接提取当前 Lens 贴图函数，检查四组尺寸的中心、固定曲线样本、蓝通道和 Alpha；再预热 3 次、对 600×600 采样 9 次，报告中位数。本次默认参数调整后中位数约 3.95ms，仅作本机记录。

该计时只包含像素数学及数组写入，不包含 PNG 编码、浏览器合成或 GPU 采样；不能据此推导帧率。旧宽弧面与旧差分实现的性能对比已移除，历史 40% 提速数据不适用于当前版本。
