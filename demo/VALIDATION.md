# 验证记录

## 2026-10-22 安卓 Edge 试验支持

用户确认反馈来自安卓 Edge，并授权尝试适配。原实现显式排除 Android UA，同时禁止 coarse 主指针。现在对 Android Chromium 开放单次 Light，保留 CSS 能力检查、尺寸上限、Canvas 失败回退及系统透明度偏好。Auto / Full / Light 请求在该平台都使用 Light；没有启用三通道 Full。触摸不触发鼠标跟随光斑。

- Host 总计 47 项通过，新增 12 项覆盖安卓 Edge UA + coarse、Full 限制为 Light、手动 Frost/Solid、触摸光斑、离屏释放、CSS/Canvas 失败、安卓 Firefox/iPhone Edge 回退及桌面行为。
- 更新浏览器质量、集成和交互检查，按照实际平台选择断言；Android Light 不被误算为 Full 覆盖，只针对 Full 的检查会跳过。
- `compatibility=android-light-experimental` 是候选路径标记，不是真机兼容性证明。实际安卓 Edge 的 SVG 背景采样、画面与 GPU 帧耗时尚未验证；CSS.supports 返回 true 不能代替这些验收。
- 本轮未改 Lens 栅格公式；此前 75 组逐像素比较仍作为光学算法回归证据。

## 2026-10-22 滚动可见性修复

用户报告连续滚动时，新进入视口的卡片仍为毛玻璃，要等 120ms 停顿才开启折射。上一轮的滚动帧只降级原本已开启的 Full，确实没有接入新卡片。

- Auto 新增 IntersectionObserver 生命周期管理，进入/离开不依赖停顿计时器。变化合并到下一动画帧；刚进入时启用 Light，停止后按原预算升级到 Full。
- 离屏释放 SVG，并关闭 backdrop blur、阴影与光斑。不创建离屏贴图几何；布局、内容节点和输入保留，不用 display:none 隐藏卡片。缓存仍有 8 张上限，回来时可复用。
- 手动 Full 保留原显式行为；其他档位下仍跟踪观察结果，避免切回 Auto 使用过期可见性。没有 IntersectionObserver 时按帧批量检查，不退回等停顿的旧行为。
- 35 项 host 检查通过，新增覆盖持续滚动中进入/离开/再次进入、同帧多次变化取最新值、祖先裁剪、切档后状态、无 observer 的回退、观察器销毁和属性恢复。
- 75 组 Lens RGBA 仍与优化前参考逐字节一致。此轮没有修改光学公式或默认参数。
- 给页面自检新增 9 项真实滚动容器检查：持续派发滚动事件保持活动，确认新卡片进入就折射、离开无 SVG/模糊、占位不变、返回复用缓存及停下后 Full。扩展后的浏览器检查尚未运行；上一轮 116/116 不作为本轮验收结果。浏览器自动化此前被 URL 安全策略拦截，未通过其他浏览器接口绕过。
- Host 环境：Windows / Node.js v26.12.1。没有新增 GPU 帧耗时结论。

相交观察与阈值语义参考 [MDN Intersection Observer](https://developer.mozilla.org/en-US/docs/Web/API/Intersection_Observer_API)。

## 2026-10-21 性能更新

用户报告独立演示页滚动和拖动窗口时卡顿。本轮保留 Full 的 SVG 图、Lens 曲线、默认参数和 CSS 材质，优化贴图计算、几何刷新与 Auto 的交互路径；只做本地提交，不推送。

- 23 项 host 检查通过：稳定刷新每面板一次尺寸读取、无重复属性写入、先读后写、显式回调、手动 Full 滚动不重扫、拖窗后更新尺寸、Auto 的暂时 Light 与恢复、突发事件合并、贴图复用、销毁清理、LRU 和动态成员同步。
- Auto 在下一帧把现有 Full 改为 Light，切换复用已知几何与贴图；120ms 无新事件后测量并恢复 Full。手动 Full 不自动降档。

## 数学与 CPU 计时

```sh
node demo/benchmark.mjs
```

脚本直接提取当前 Lens 贴图函数，检查四组尺寸的中心、固定曲线样本、蓝通道和 Alpha；再预热 3 次、对 600×600 采样 9 次，报告中位数。本次默认参数调整后中位数约 3.95ms，仅作本机记录。

该计时只包含像素数学及数组写入，不包含 PNG 编码、浏览器合成或 GPU 采样；不能据此推导帧率。旧宽弧面与旧差分实现的性能对比已移除，历史 40% 提速数据不适用于当前版本。
